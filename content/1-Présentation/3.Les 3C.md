# Character
 Le joueur incarne une chasseresse utilisant un artéfact étrange capable d'arrêter le temps pour retrouver sa tribu disparue.
# Camera
- **Type :**
	- Vue **top-down**.

- **Comportement**
	- Caméra active centrée sur le joueur
	- Possibilité de **se placer à un point fixe** selon le contexte narratif (ex. : salle de combat, salle de boss).
	- Possibilité de **zoom et de modification du point d'intérêt** selon le contexte narratif (ex: scène de poursuite, focus sur un objet clé etc...)
# Control
Le personnage peut se déplacer, attaquer, arrêter le temps et activer des mécanismes via clavier/souris ou manette.
